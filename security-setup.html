Secure your LabCore account

Before continuing, set a strong password and pair an authenticator app. This replaces temporary PIN sign-in and is required for all staff accounts.

Set up authenticator app

In Google Authenticator, Microsoft Authenticator, 1Password or another TOTP app, choose “Add account” → “Enter setup key”. Use issuer LabCore and the key below. The code changes every 30 seconds.

If you did not start this setup, cancel and sign out.
