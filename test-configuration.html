Each sub-test has its own result type — e.g. Malaria RDT = Qualitative, Parasite Density = Quantitative, Species = Categorical. For qualitative/categorical tests you must define the allowed options AND which one is normal.

Allowed Result Options & Normal Value
Note: Qualitative and categorical results are reported as text (Positive, Reactive, Detected, etc.). They are never flagged H or L. The flag column will show a dash for these tests. The result text itself is coloured to show normal vs abnormal.
Pick exactly one option as Normal. Options marked Invalid/Indeterminate are treated separately and never flagged as abnormal.
